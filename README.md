## Instalación y Configuración

### Requisitos Previos
- Python 3.10 o superior
- pip (gestor de paquetes de Python)
- Git

### Instalación de Dependencias

```bash
# Clonar el repositorio (REEMPLAZA 'tu-usuario' con tu usuario real de GitHub)
git clone https://github.com/tu-usuario/machine-learning-practicas.git
cd machine-learning-practicas

# Instalar dependencias principales
pip install numpy pandas matplotlib seaborn scikit-learn

# Para Deep Learning
pip install tensorflow keras

# Para NLP
pip install spacy nltk transformers sentence-transformers
python -m spacy download es_core_news_sm

# Para Computer Vision
pip install opencv-python ultralytics

# Para Reinforcement Learning
pip install gymnasium

# Para optimización
pip install optuna
